# Decisiones clínicas pendientes

Ficha limitada al elemento inferior del boceto. No describe el sistema editorial ni las cuatro hojas ya maquetadas.

## Elemento inferior excluido

En la parte inferior del boceto completo aparece un diagrama aparte de las cuatro áreas de formato:

- varios círculos unidos por una línea horizontal;
- un círculo con conexión vertical hacia arriba;
- un círculo con conexión vertical hacia abajo;
- a la derecha, el texto `Otro` y una línea horizontal.

Este diagrama **no pertenece a ninguna de las cuatro hojas** (Expedientes, Paciente Rx/Tx, Eventos, Paciente imagen). **No es un odontograma.** Su uso clínico no está definido en el boceto.

Queda como **alcance clínico futuro**. Su exclusión **no bloquea** las cuatro hojas actuales: se imprimen e identifican de forma independiente, sin incorporar este diagrama.

## Alternativas futuras (sin implementar)

Hasta que el médico confirme significado y pertenencia, no se maqueta el diagrama. Las dos alternativas de ubicación, pendientes de validación, son:

1. **Quinta hoja o anexo independiente**, con su propio código documental, para archivar o escanear por separado.
2. **Componente opcional en el Formato 4** (Paciente / imagen / leyenda), **solo si** el médico confirma que el diagrama está ligado a la imagen y a su leyenda Rojo / Azul / Verde / Otro.

## Preguntas de validación médica

Hay que resolver estas preguntas antes de diseñar el diagrama de manera definitiva:

1. ¿Qué representa cada círculo?
2. ¿Qué significa cada conexión?
3. ¿El orden horizontal es secuencial, anatómico o temporal?
4. ¿Qué representa el círculo superior?
5. ¿Qué representa el círculo inferior?
6. ¿Qué debe escribirse en el campo “Otro”?
7. ¿Debe llenarse a mano, marcarse o relacionarse con un elemento de imagen?
